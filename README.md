# TravelGuesser

Un jeu type GeoGuessr pour les avions. Tu vois un avion passer au-dessus de toi, tu devines son modèle, sa compagnie et sa destination.

## Stack
- HTML/CSS/JS vanilla (un seul fichier)
- API Vercel serverless pour proxifier OpenSky Network

## Test local
Tu peux ouvrir `index.html` directement dans un navigateur (mode démo uniquement).

## Déploiement
Push sur GitHub puis import dans Vercel. Pas de config nécessaire.
